# マイドクターペイ（本人専用）v1.0

「ドクターペイ」の配色・画面構成を参考にした、本人用の独立した静的Webアプリです。

## 主な仕様
- 常勤：基本給、変動する残業代、賞与、交通費、その他支給額を振込月ごとに入力。健康保険、厚生年金、介護保険、雇用保険、住民税、源泉所得税、企業型DC（本人拠出分）を確定明細として記録。
- 定期非常勤：曜日、祝日休み・祝日勤務、日額、交通費、勤務月から振込までの月数を設定。祝日規則による月次自動計算と回数の手修正、予想額面の直接上書きが可能。
- スポット：日付登録なし。給与を振込月単位で記録。同じ勤務先の同月複数件に対応。
- 給与：予想額面を先行入力し、確定後に額面と手取りをセットで入力。額面と手取りの差額を源泉所得税と自動的にはみなさない。
- 年間集計：確定額面を優先した年収見込と、確定手取りの実績。
- 2026/2027年の所得税・ふるさと納税：簡易試算。控除要件等の未対応項目があるので参考値扱い。本人拠出DCのみ所得控除対象。
- 端末のブラウザ内保存／JSONバックアップ・復元／年間CSV書き出し。

## 公開方法（既存のdoctor-payを変更しない）

1. GitHubで **新しい** repository `my-doctor-pay` を作成してください（元の `doctor-pay` とは別にしてください）。
2. このZIP内の `index.html`、`manifest.webmanifest`、`service-worker.js`、`icon-192.png`、`icon-512.png` を **リポジトリの直下** にアップロードして `Commit changes`。
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save。
4. URL は `https://michisamichi.github.io/my-doctor-pay/` となる予定です（実際に公開されるまでは開けません）。
5. SafariでURLを開き、共有メニューから「ホーム画面に追加」。

## 重要事項
- 妻用アプリと異なるリポジトリ・保存キーです。妻用のJSONはインポートできません。
- GitHub Pagesの `Public` リポジトリに入れた**プログラムは公開**されます。実際の給与金額はWebアプリ上の端末内保存であり、ソースコードには含まれません。**給与明細やバックアップJSONをGitHubへアップロードしないでください。**
- GitHub Pages公開前にHTMLをファイルから直接開いた場合は一部ブラウザで保存に制限があります。公開URLからの使用を推奨します。
- 祝日は2020〜2099年の一般的な祝日規則から算出。臨時祝日や特殊なシフトは手動補正してください。
- 2026/2027年分の税額試算は、給与所得のみを仮定した概算です。年末調整・確定申告・自治体の試算の代用にはなりません。
