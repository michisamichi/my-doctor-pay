# Dr.Pay

医師の給与・税金管理用 Web アプリ（PWA）。

- [アプリを開く](https://michisamichi.github.io/my-doctor-pay/)
- [開発方針・仕様・引き継ぎ（AGENTS.md）](AGENTS.md)

## 利用方法

iPhone の Safari で公開先を開き、共有メニューから「ホーム画面に追加」できます。給与データは端末のブラウザ内に保存します。設定から JSON バックアップ・復元が可能です。

## 開発

最新版はこのリポジトリの main ブランチです。開発を再開する際は AGENTS.md と最新ソースを確認してください。アプリは GitHub Pages で公開します。

## 注意

このリポジトリは公開されています。給与明細、バックアップ JSON、個人情報、秘密情報はコミットしないでください。税金・ふるさと納税の試算は概算であり、確定申告や自治体の実際の税額の代用ではありません。
